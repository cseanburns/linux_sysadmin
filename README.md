# Linux Sys Admin

This repository contains material for a course on Linux systems administration.
The content is written in markdown (see **src/** directory) and is built using [mdBook][mdbook].

The first version of this book was taught using virtual machines on Google Cloud.
That version has been archived as a [release](https://github.com/cseanburns/linux_sysadmin/releases/tag/gcloud_version).

The next version (as of Fall 2026) uses a different hosting service.

The book is hosted using GitHub Pages: [https://cseanburns.github.io/linux_sysadmin/](https://cseanburns.github.io/linux_sysadmin/)

I consider this book a live document that will be updated throughout the year, especially in the fall semesters.

The **archive/** directory contains prior content that I want to save separately.

I do not accept automatic pull requests because I designed this book around how I teach this material.
However, if you find this work useful, feel free to fork it;
it is licensed under the [GPL-3.0](https://github.com/cseanburns/linux_sysadmin?tab=GPL-3.0-1-ov-file).
